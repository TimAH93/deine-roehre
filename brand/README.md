# Emblem

Put the Archon Grid emblem here from your PC, e.g. `archon-grid.png`
(a PNG with transparency is best). The app takes the first image whose name
contains `archon`, `archon-grid.*` first. Without it, the home control shows
the words "Deine Röhre" in Fraktur.

Pictures are not committed for now (the emblem is Tim's; Anna decides art).
